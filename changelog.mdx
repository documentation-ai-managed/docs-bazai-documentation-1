## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added real-time collaboration features allowing multiple users to edit documents simultaneously
- Introduced advanced search with filters and faceted navigation
- Implemented document versioning with automatic snapshots
- Added support for custom themes and branding options

## Improvements

- Enhanced editor performance with faster loading times
- Improved API response times by 40%
- Added keyboard shortcuts for common actions
- Better mobile responsiveness across all devices

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["feature", "breaking"]}>

## New Features

- Complete redesign of the user interface with modern components
- New API endpoints for programmatic content management
- Integration with popular CI/CD platforms
- Advanced permission system with role-based access control

## Breaking Changes

- API v1 endpoints are deprecated; migrate to v2 by end of year
- Folder structure changes require content reorganization
- Authentication flow updated; existing tokens need refresh

</Update>
