## Organization & Structure

Keep your documentation organized with powerful structuring tools. Create hierarchical folders, apply tags, and use custom metadata to categorize and find content.

<Steps>
  <Step title="Create Folders" icon="folder">
    Organize content into logical folders and subfolders. Drag and drop to rearrange the structure.
  </Step>
  <Step title="Apply Tags" icon="tag">
    Add tags to documents for easy categorization and filtering. Create custom tag hierarchies.
  </Step>
  <Step title="Set Metadata" icon="settings">
    Add custom metadata fields like author, status, and priority to track document properties.
  </Step>
  <Step title="Configure Permissions" icon="lock">
    Control who can view and edit documents with granular permission settings.
  </Step>
</Steps>

## Integration Capabilities

Connect Bazai with your existing tools and workflows. Import content from other platforms and automate documentation updates.

<Tabs>
  <Tab title="Git Integration" icon="git-branch">
    Connect to Git repositories for version control and automated deployments.

    <CodeGroup tabs="GitHub,Bitbucket">
      ```bash
git clone https://github.com/your-org/docs.git
cd docs
npm install
npm run build
      ```
      ```bash
git clone https://bitbucket.org/your-org/docs.git
cd docs
npm install
npm run build
      ```
    </CodeGroup>
  </Tab>
  <Tab title="API Access" icon="code">
    Use our REST API to programmatically manage documentation content.

    <Request tabs="Create Document,Update Document" show-lines="true">
      ```javascript
const response = await fetch('/api/docs', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    title: 'New Document',
    content: '# Hello World'
  })
});
      ```
      ```javascript
const response = await fetch('/api/docs/123', {
  method: 'PUT',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    title: 'Updated Document',
    content: '# Updated Content'
  })
});
      ```
    </Request>
  </Tab>
