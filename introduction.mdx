## Getting Started

Bazai Documentation is your default documentation space for organizing and managing all your project documentation. It provides a centralized platform to create, edit, and share comprehensive documentation with your team and users. With intuitive features and powerful tools, you can build professional documentation sites that scale with your projects.

## Key Features

Bazai Documentation offers a comprehensive set of features designed to streamline your documentation process. From rich text editing to advanced search capabilities, you can create engaging documentation that meets the needs of both technical and non-technical audiences.

<Tabs>
  <Tab title="Writing" icon="file-text">
    Use our powerful editor to create rich content with support for code blocks, tables, and embedded media. The editor includes markdown support and live preview capabilities.

    <CodeGroup tabs="Markdown,Rich Text">
      ```markdown
# Sample Documentation

This is a sample document showing how to use **bold text** and `inline code`.

| Feature | Description |
|---------|-------------|
| Markdown | Support for standard markdown syntax |
| Live Preview | See changes in real-time |
      ```
      ```html
<h1>Sample Documentation</h1>
<p>This is a sample document showing how to use <strong>bold text</strong> and <code>inline code</code>.</p>
<table>
  <tr><th>Feature</th><th>Description</th></tr>
  <tr><td>Rich Text</td><td>Full WYSIWYG editing experience</td></tr>
  <tr><td>Media Embed</td><td>Insert images, videos, and interactive content</td></tr>
</table>
      ```
    </CodeGroup>
  </Tab>
  <Tab title="Organization" icon="folder">
    Keep your documentation organized with hierarchical folders, tags, and custom metadata. Set permissions and access controls to manage who can view and edit content.

    <Expandable title="Folder Structure Example" default-open="false">
      ```
      docs/
      ├── getting-started/
      │   ├── introduction.md
      │   └── quick-start.md
      ├── api-reference/
      │   ├── authentication.md
      │   └── endpoints.md
      └── advanced/
          ├── integrations.md
          └── troubleshooting.md
      ```
    </Expandable>
  </Tab>
  <Tab title="Collaboration" icon="users">
    Collaborate with your team using comments, suggestions, and version history. Track changes and maintain a complete audit trail of all documentation updates.

    <Callout kind="tip">
      Enable real-time collaboration to see live edits from team members and resolve conflicts automatically.
    </Callout>
  </Tab>
</Tabs>
