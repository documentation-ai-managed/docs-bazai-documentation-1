## Getting Started with the API

To start using the Bazai API, you'll need to obtain an API key and understand the basic request structure.

<Steps>
  <Step title="Get API Key" icon="key">
    Generate an API key from your account settings. Keep this key secure and don't share it publicly.
  </Step>
  <Step title="Make Test Request" icon="send">
    Test your API key with a simple GET request to verify authentication works.
  </Step>
  <Step title="Explore Endpoints" icon="search">
    Review the available endpoints and their parameters in our API reference.
  </Step>
  <Step title="Build Integration" icon="code">
    Start building your integration using the SDK or direct API calls.
  </Step>
</Steps>

<CodeGroup tabs="cURL,JavaScript,Python">
  ```bash
curl -X GET \
  'https://api.bazai.com/v1/docs' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json'
  ```
  ```javascript
const response = await fetch('https://api.bazai.com/v1/docs', {
  method: 'GET',
  headers: {
    'Authorization': `Bearer ${API_KEY}`,
    'Content-Type': 'application/json'
  }
});
const docs = await response.json();
  ```
  ```python
import requests

response = requests.get(
    'https://api.bazai.com/v1/docs',
    headers={
        'Authorization': f'Bearer {API_KEY}',
        'Content-Type': 'application/json'
    }
)
docs = response.json()
  ```
</CodeGroup>

## Authentication

The Bazai API uses Bearer token authentication. Include your API key in the Authorization header for all requests.

<Callout kind="danger">
  Never expose your API key in client-side code or public repositories. Use environment variables or secure key management systems.
</Callout>

<Tabs>
  <Tab title="API Key" icon="key">
    Use a single API key for all requests. This is the simplest authentication method.

    ```bash
export API_KEY="your_api_key_here"
curl -H "Authorization: Bearer $API_KEY" https://api.bazai.com/v1/docs
    ```
  </Tab>
  <Tab title="OAuth 2.0" icon="lock">
    For more advanced scenarios, use OAuth 2.0 for delegated access and fine-grained permissions.

    <Expandable title="OAuth Flow" default-open="false">
      1. Redirect user to authorization URL
      2. User grants permissions
      3. Receive authorization code
      4. Exchange code for access token
      5. Use token for API requests
    </Expandable>
  </Tab>
</Tabs>

## Core API Endpoints

The API provides endpoints for managing documents, folders, users, and more.

<ExpandableGroup>
  <Expandable title="Document Management" default-open="true">
    - `GET /docs` - List all documents
    - `POST /docs` - Create new document
    - `GET /docs/{id}` - Get document details
    - `PUT /docs/{id}` - Update document
    - `DELETE /docs/{id}` - Delete document
  </Expandable>
  <Expandable title="Folder Operations" default-open="false">
    - `GET /folders` - List folders
    - `POST /folders` - Create folder
    - `PUT /folders/{id}` - Update folder
    - `DELETE /folders/{id}` - Delete folder
  </Expandable>
  <Expandable title="User Management" default-open="false">
    - `GET /users` - List users
    - `POST /users` - Invite user
    - `PUT /users/{id}` - Update user permissions
  </Expandable>
</ExpandableGroup>

## Working with Documents

Documents are the core content type in Bazai. Learn how to create, update, and manage documents programmatically.

<Request tabs="Create Document,Update Document" show-lines="true">
  ```javascript
const createDoc = async (title, content) => {
  const response = await fetch('/api/docs', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      title: title,
      content: content,
      folder_id: 'folder_123',
      tags: ['api', 'guide']
    })
  });
  return response.json();
};
  ```
  ```javascript
const updateDoc = async (id, updates) => {
  const response = await fetch(`/api/docs/${id}`, {
    method: 'PUT',
    headers: {
      'Authorization': `Bearer ${API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(updates)
  });
  return response.json();
};
  ```
</Request>

## Webhooks

<Callout kind="info">
  Webhooks allow you to automate workflows and keep external systems in sync with your documentation.
</Callout>

<Tabs>

{
  "url": "https://your-app.com/webhooks/docs",

  "secret": "your_webhook_secret"

## SDKs and Libraries

Official SDKs make integration easier by handling authentication, retries, and error handling.

<CodeGroup tabs="Node.js,Python,Go">
  ```javascript
// Install SDK
npm install @bazai/sdk

// Initialize client
const { BazaiClient } = require('@bazai/sdk');
const client = new BazaiClient({ apiKey: 'your_key' });

// List documents
const docs = await client.docs.list();
  ```
  ```python
# Install SDK
pip install bazai-sdk

# Initialize client
from bazai import BazaiClient
client = BazaiClient(api_key='your_key')

# List documents
docs = client.docs.list()
  ```
  ```go
// Install SDK
go get github.com/bazai/go-sdk

// Initialize client
import "github.com/bazai/go-sdk"
client := bazai.NewClient("your_key")

// List documents
docs, err := client.Docs.List()
  ```
</CodeGroup>

## Error Handling

Handle API errors gracefully with proper error codes and messages.

<Expandable title="Common Error Codes" default-open="false">
  - `400 Bad Request` - Invalid request parameters
  - `401 Unauthorized` - Invalid or missing API key
  - `403 Forbidden` - Insufficient permissions
  - `404 Not Found` - Resource doesn't exist
  - `429 Too Many Requests` - Rate limit exceeded
  - `500 Internal Server Error` - Server error
</Expandable>

<Callout kind="tip">
  Implement exponential backoff for retry logic and monitor your API usage to stay within rate limits.
</Callout>
